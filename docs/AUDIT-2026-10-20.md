# Architecture audit and gap analysis: 2026-10-20

Scope: the `graph_engineering/` repository at `3a3dacf` (branch
`feat/accepted-ticket-autonomy`), audited on macOS 26 (Darwin 25.6) with Python 3.11,
OpenCode 2.0.32, Git 2.53 and gh 2.102. It was previously developed and exercised on
Windows 11. The evidence used is source code, test runs, live endpoint and OpenCode
calls, and runtime traces. README claims were not taken as evidence.

## What already worked (verified, kept)

* **Durable execution core.** SQLite WAL with state and event in one transaction,
  OS-lock ownership, a per-node subprocess leasing scheduler, crash fencing, and an
  effect ledger with fail-closed reconciliation. Sound and well tested. A live
  `kill -9` of the scheduler and its in-flight worker on 2026-10-20 recovered without
  duplication.
* **Verification and policy.** Frozen tests and policy files, diff-scope checks,
  head-bound human approvals, merge gates that recheck fresh CI and policy, no admin
  bypass. Automatic merge is off by default.
* **Natural-language intake.** The original report is persisted before inference.
  Triage, literal committed-source retrieval, investigation, and deterministic
  file/line/quote validation keep hypotheses and verified references separate.
* **Control centre.** Animation is driven only by persisted SSE events. Board and
  graph share one snapshot. No `innerHTML`, strict CSP, CSRF and Host checks.
  The Edge and axe browser suites pass.
* **OpenCode workers.** A fresh profile per call, every tool denied, JSON-schema
  output validated locally.
